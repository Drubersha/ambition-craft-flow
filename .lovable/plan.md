
## Изменения навигации (`src/components/app-shell.tsx`)

Новый порядок пунктов меню для главного/менеджера:

1. Дашборд
2. **Воронка** — поднята на верх (после Дашборда)
3. **Объекты** — `/properties` (пункт «Папки» удалён)
4. Арендаторы
5. Договоры
6. **Оплаты** — `/payments` (пункт «Начисления» удалён)
7. Задачи
8. Чаты

## Раздел «Объекты» (`src/routes/_authenticated/properties.index.tsx`)

Внутри страницы добавляются вкладки (Tabs):
- **Список** — текущий список объектов (как сейчас).
- **Папки** — содержимое из `src/routes/_authenticated/folders.tsx` (дерево папок + drag-n-drop объектов), встроенное в эту же страницу.

Файл `folders.tsx` превращается в переиспользуемый компонент `src/components/folders-view.tsx` и подключается во вкладке «Папки». Сам маршрут `/folders` удаляется (старые ссылки на него заменяются на `/properties`).

## Раздел «Оплаты» (`src/routes/_authenticated/payments.index.tsx`)

Страница переименовывается в «Оплаты» и получает вкладки:
- **Начисления** — содержимое из `charges.index.tsx`.
- **Платежи** — текущее содержимое `payments.index.tsx`.

Логика выносится в компоненты `src/components/charges-list.tsx` и `src/components/payments-list.tsx`. Маршрут `/charges` остаётся для совместимости (ссылки из договоров/арендаторов), но из меню убирается; редиректов не делаем — существующие ссылки продолжают работать.

## Что НЕ меняется

- БД, серверные функции, права доступа.
- Меню арендатора (`/me/*`).
- Функциональность списков, фильтров, действий — только перекомпоновка.
