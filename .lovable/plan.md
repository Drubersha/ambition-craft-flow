## Что добавляем

Возможность нарисовать на плане папки (карте территории) фигуру для каждого объекта — многоугольник или круг/маркер. При наведении мышью на фигуру показывается всплывающая подсказка: название объекта, площадь, базовая ставка за м², данные активного договора (ставка и платёж за период).

Объект отмечается на плане **своей папки и всех родительских** папок: одна и та же фигура может быть нарисована отдельно для каждого уровня (например, грубый контур на плане всего комплекса и точный — на плане конкретного здания).

Редактировать разметку могут только владелец и менеджер (как и сейчас для прочих данных).

## UX

На странице папки (`/folders`), под блоком карты:
- Кнопка «Режим разметки» (toggle). Включает overlay поверх PlanViewer.
- В режиме разметки сверху панель: выбор объекта из списка (объекты этой папки + подпапок), выбор инструмента (Многоугольник / Маркер), кнопки «Сохранить», «Удалить», «Отмена».
- Многоугольник: клики добавляют точки, двойной клик/Enter — замкнуть.
- Маркер: один клик ставит точку (опционально — drag для радиуса круга).
- Координаты хранятся в нормализованном виде (0..1 по ширине/высоте плана) — чтобы зум/панорамирование PlanViewer не ломали привязку.

Вне режима разметки:
- Фигуры всех объектов папки отрисованы поверх плана как SVG-overlay внутри PlanViewer (трансформируются вместе с изображением).
- Hover по фигуре → tooltip: имя объекта, площадь (м²), базовая ставка (₽/м²), а если есть активный договор — его ставка и платёж за период с подписью периода (месяц/квартал/год).
- Клик по фигуре → переход на страницу объекта.

## Технические детали

### Схема БД (новая миграция)

Новая таблица `public.property_markings`:
- `property_id uuid` → `properties(id) on delete cascade`
- `folder_id uuid` → `folders(id) on delete cascade` — на чьей карте нарисовано
- `shape text` — `'polygon' | 'circle' | 'point'`
- `coords jsonb` — нормализованные координаты:
  - polygon: `{ points: [[x,y], …] }`
  - circle: `{ cx, cy, r }`
  - point: `{ cx, cy }`
- `color text null` (опционально, для будущего)
- `owner_id`, `created_at`, `updated_at`
- UNIQUE `(property_id, folder_id)` — одна фигура на пару объект/папка.

GRANT для `authenticated`, `service_role`. RLS: `owner_id = auth.uid()`. Триггер `touch_updated_at`.

### Frontend

- `src/components/plan-markup-overlay.tsx` — SVG overlay внутри `PlanViewer`: рендер фигур + hit-test для hover-tooltip.
- `src/components/plan-markup-editor.tsx` — режим редактирования (рисование многоугольника/маркера, сохранение в БД).
- Расширить `PlanViewer` пропом `overlay?: ReactNode`, который отрисовывается в трансформируемом слое поверх PNG (вместе со scale/translate).
- На странице `/folders`: загрузить разметку всех объектов, чьи цепочки папок включают текущую папку (объекты из самой папки и всех вложенных), плюс активные договоры этих объектов одним запросом для tooltip.
- Tooltip — лёгкий компонент на CSS (position: absolute по координатам курсора внутри overlay).

### Что НЕ меняем

- PlanViewer (зум/пан/полноэкран) — только добавляем слот для overlay.
- Загрузка планов, конвертация в PNG, структура папок и объектов.
- RLS других таблиц.
