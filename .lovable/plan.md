
## Что можно сделать

Можно реализовать практически всё MVP из вашего ТЗ как адаптивное веб-приложение (PWA-ready) на TanStack Start + Lovable Cloud (Postgres, Auth, Storage). Не входит в MVP: онлайн-эквайринг, нативные iOS/Android, CAD-редактор плана помещений, интеграции с банками/мессенджерами, многоарендодательность и сложный кабинет арендатора — это Фаза 2+.

## Скоуп MVP (Фаза 1)

1. **Аутентификация** — email+пароль через Lovable Cloud, одна роль `owner` (роль `manager` отложена).
2. **Дашборд** — KPI (объекты: всего/занято/свободно), финансы за месяц (начислено/оплачено/просрочено), список должников, договоры с близким окончанием (30/14/7 дней), последние платежи.
3. **Объекты и помещения** — CRUD, поля: название, адрес, тип, кадастровый №, площадь общая/полезная, этаж, № помещения, статус, базовая ставка, валюта, описание, фото/документы. Авторасчёт статуса занятости по активным договорам.
4. **Арендаторы** — CRUD: ФИО/компания, контакты, ИНН/реквизиты, заметки. В карточке обязательно: № договора, кадастровый №, площадь, цена/ставка (как требует п. 0.1.8).
5. **Договоры** — связь арендатор↔помещение, № договора, даты начала/окончания, ставка, периодичность оплаты, файл договора, статус (черновик/активный/завершён/расторгнут).
6. **Начисления и счета** — ручное и автогенерация по периодичности договора, доп. строки (коммуналка, парковка, пени), статус оплаты, остаток долга.
7. **Платежи** — ручная отметка оплаты (дата, сумма, способ, комментарий), поддержка частичной оплаты, история по арендатору.
8. **Документы** — загрузка файлов к объекту/арендатору/договору в Lovable Cloud Storage.
9. **Поиск и фильтры** — глобальный поиск по арендатору (имя/телефон/ИНН), объекту (адрес/кадастр), договору (№), счетам.
10. **Экспорт** — CSV-экспорт списков (арендаторы, договоры, начисления, платежи).
11. **Напоминания** — внутри приложения: бейджи и список «требует внимания» (просрочки, скорое окончание). Email-уведомления — Фаза 2.

## Что НЕ входит в MVP (Фаза 2+)

- Кабинет арендатора (заменяется PDF/ссылками вручную).
- Онлайн-оплата / эквайринг.
- Графический план помещения (можно начать с таблицы зон).
- Заявки на обслуживание (можно добавить простой модуль позже).
- Роль «управляющий» с гранулярными правами.
- Telegram/MAX/email-нотификации, интеграции с банками, 1С.
- Нативные мобильные приложения.

## Структура данных (Lovable Cloud / Postgres)

```
profiles            (id, full_name, …)
user_roles          (user_id, role enum: owner)
properties          (объект: id, name, address, type, cadastral_no, area_total, area_usable, floor, room_no, status, base_rate, currency, description, owner_id)
property_files      (id, property_id, storage_path, kind)
tenants             (id, name, type[person|company], inn, phone, email, notes, owner_id)
contracts           (id, tenant_id, property_id, number, cadastral_no, area, rate, currency,
                     start_date, end_date, payment_period enum, status, file_path, owner_id)
charges             (id, contract_id, period_start, period_end, total, status)
charge_items        (id, charge_id, kind, description, amount)
payments            (id, charge_id, paid_at, amount, method, comment)
documents           (id, owner_kind[property|tenant|contract], owner_id, storage_path, label)
```
RLS: всё фильтруется по `owner_id = auth.uid()`. Роли в отдельной таблице `user_roles` (security definer `has_role`).

## Технический стек

- TanStack Start (уже в проекте) + React 19 + Tailwind v4 + shadcn/ui.
- Lovable Cloud: Postgres (RLS), Auth (email/password), Storage (документы/фото).
- TanStack Query для загрузки данных через server functions.
- Маршруты под `_authenticated/`: `/dashboard`, `/properties`, `/properties/$id`, `/tenants`, `/tenants/$id`, `/contracts`, `/contracts/$id`, `/charges`, `/payments`, `/settings`. Публичные: `/auth`.
- PWA-манифест и адаптивная вёрстка под мобильный/планшет/десктоп.

## План реализации по итерациям

1. Включить Lovable Cloud, настроить Auth + роли + RLS, базовый layout и навигацию.
2. Модуль «Объекты» (CRUD + загрузка фото/документов).
3. Модуль «Арендаторы» (CRUD).
4. Модуль «Договоры» (CRUD + связи + загрузка файла + статусы).
5. «Начисления» и «Платежи» (CRUD, частичные оплаты, расчёт долга).
6. Дашборд (KPI, должники, скорое окончание, последние платежи).
7. Глобальный поиск, фильтры, CSV-экспорт.
8. Полировка: пустые состояния, валидация, мобильная адаптация, PWA-манифест.
